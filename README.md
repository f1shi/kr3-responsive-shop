## Lighthouse

Проверены страницы:

- `index.html`;
- `catalog.html`;
- `order.html`;
- `product.html`;
- `contacts.html`.

Результат категории Accessibility до исправлений: 95 на `index.html` и `catalog.html`.
Результат после исправлений: 100 на всех проверенных страницах.

Отчёт сохранён в папке `lighthouse/`:

- `accessibility-report.png` — скриншот итогового отчёта;
- `accessibility-report-index.html`, `accessibility-report-catalog.html`, `accessibility-report-order.html` — отчёты после исправлений;
- `accessibility-report-before.html` — отчёт до исправлений.

## Исправления доступности

| Проблема | Исправление |
|----------|-------------|
| Недостаточный контраст бейджей «Скидка» (3.18:1) и «Новинка» (4.45:1) | Цвета заменены на `#b45309` и `#146c2e`, контраст выше 4.5:1 |
| Светло-серый вспомогательный текст | `--color-muted` изменён на `#4b5563` |
| Нет быстрого перехода к содержимому | Добавлена `skip-link` и `id="main"` у `main` |
| Текущая страница не обозначена для скринридеров | Добавлен `aria-current="page"` в меню и хлебных крошках |
| Две навигации без подписей | Добавлен `aria-label` у навигации в подвале |
| Неравномерный фокус | Единый стиль `:focus-visible` с `outline: 3px` |
| Ошибки формы видны только по цвету рамки | Добавлены текстовые сообщения, связанные с полями через `aria-describedby` |
| Подсказка формата телефона не связана с полем | Подсказка связана через `aria-describedby` |
| Нет пояснения про обязательные поля | Добавлен текст о полях со звёздочкой |
| В таблице нет заголовков строк | Первый столбец оформлен через `th scope="row"` |
| Модальное окно без описания | Добавлен `aria-describedby` и подпись кнопки закрытия |
| Сообщение об успехе не озвучивается | Добавлен `role="status"` |
| В хлебных крошках товара «Каталог» не был ссылкой | Заменён на ссылку на `catalog.html` |
