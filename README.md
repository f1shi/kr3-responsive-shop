## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина электроники ShopProject. Основа перенесена из КР №1, Bootstrap не используется.

## Адаптивные решения

- добавлен файл `css/responsive.css`, подключённый после `css/style.css` на всех страницах;
- применён подход Mobile First с медиазапросами `min-width`: 640, 768, 900, 1024, 1280px;
- контейнеры задаются через `width: min(100% - 32px, var(--container-width))`, отступы секций через `clamp()`;
- навигация на мобильном экране сворачивается в кнопку «Меню», на планшете и desktop выстраивается в строку;
- шапка становится sticky только начиная с 768px;
- hero-блок одноколоночный на мобильном и двухколоночный с 900px, заголовок масштабируется через `clamp()`;
- сетка карточек: 1 → 2 → 3 → 4 колонки;
- каталог: фильтр над товарами на мобильном, sticky-фильтр слева с 1024px;
- изображения карточек подключены через `srcset` и `sizes` (480, 640, 960px), `loading="lazy"`;
- hero-изображение подключено через `picture` с разными файлами для мобильного, планшета и desktop;
- изображение на странице товара подключено через `picture` с WebP и JPEG;
- формы в одну колонку на мобильном и в две колонки с 768px, поля высотой не менее 44px;
- таблица характеристик в контейнере с горизонтальной прокруткой, а на экранах до 640px показывается карточками;
- модальное окно на мобильном экране открывается снизу на всю ширину, кнопки действий закреплены;
- учитывается настройка `prefers-reduced-motion`.

## Lighthouse

Проверены страницы:

- `index.html`;
- `catalog.html`;
- `order.html`;
- `product.html`;
- `contacts.html`.

Результат категории Accessibility до исправлений: 95 на `index.html` и `catalog.html`.
Результат после исправлений: 100 на всех проверенных страницах.

Отчёт сохранён в папке `lighthouse/`:

- `accessibility-report.png` — скриншот итогового отчёта;
- `accessibility-report-index.html`, `accessibility-report-catalog.html`, `accessibility-report-order.html` — отчёты после исправлений;
- `accessibility-report-before.html` — отчёт до исправлений.

## Исправления доступности

| Проблема | Исправление |
|----------|-------------|
| Недостаточный контраст бейджей «Скидка» (3.18:1) и «Новинка» (4.45:1) | Цвета заменены на `#b45309` и `#146c2e`, контраст выше 4.5:1 |
| Светло-серый вспомогательный текст | `--color-muted` изменён на `#4b5563` |
| Нет быстрого перехода к содержимому | Добавлена `skip-link` и `id="main"` у `main` |
| Текущая страница не обозначена для скринридеров | Добавлен `aria-current="page"` в меню и хлебных крошках |
| Две навигации без подписей | Добавлен `aria-label` у навигации в подвале |
| Неравномерный фокус | Единый стиль `:focus-visible` с `outline: 3px` |
| Ошибки формы видны только по цвету рамки | Добавлены текстовые сообщения, связанные с полями через `aria-describedby` |
| Подсказка формата телефона не связана с полем | Подсказка связана через `aria-describedby` |
| Нет пояснения про обязательные поля | Добавлен текст о полях со звёздочкой |
| В таблице нет заголовков строк | Первый столбец оформлен через `th scope="row"` |
| Модальное окно без описания | Добавлен `aria-describedby` и подпись кнопки закрытия |
| Сообщение об успехе не озвучивается | Добавлен `role="status"` |
| В хлебных крошках товара «Каталог» не был ссылкой | Заменён на ссылку на `catalog.html` |

## Самостоятельные доработки

1. **Сворачиваемое мобильное меню** с кнопкой, `aria-expanded`, `aria-controls` и закрытием по Esc. Без JavaScript меню остаётся открытым.
2. **Карточное представление таблицы** характеристик на экранах до 640px.
3. **Реальные responsive images**: три размера изображений товаров, отдельные кадры hero для разных экранов и WebP на странице товара.
4. **Мобильная версия модального окна** в виде нижней панели с закреплёнными кнопками.
5. **Текстовые сообщения об ошибках** формы, связанные с полями через `aria-describedby`.
6. **Поддержка `prefers-reduced-motion`.**
7. **Lighthouse Accessibility 100** на всех пяти страницах, сохранены отчёты до и после исправлений.
8. **Публикация через GitHub Pages.**

## Как проверить

1. Открыть ссылку GitHub Pages или `index.html`.
2. В DevTools проверить ширины 360, 430, 768, 1024 и 1440px.
3. На мобильной ширине открыть меню кнопкой «Меню».
4. Открыть `catalog.html` и проверить сетку карточек и фильтр.
5. Открыть `product.html` и проверить изображение и таблицу на ширине 360px.
6. Открыть `order.html`, отправить пустую форму и проверить сообщения об ошибках.
7. Пройти страницы клавишей Tab, проверить skip-link и фокус.
8. Открыть папку `lighthouse/`.
